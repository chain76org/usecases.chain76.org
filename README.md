# usecases.chain76.org

This project is built based on [best practices documented in github-pages-template](https://github.com/fulldecent/github-pages-template), commit 7f01f52a68a7480c4df8841be7fc2614d60ca930. The lint workflow is that commit's .github/workflows/lint.yml. Jekyll build scripts from the template are omitted. `.prettierignore` lists `assets/js/` and `assets/lib/` because those files are third-party scripts. Markdownlint also turns off heading increment, because existing pages jump from a top heading to a third-level heading. Pushes to master run the lint workflow, because master is the default branch.
